CJITS Engineering College Website
=================================
Technology: PHP + HTML5 + CSS3 + JavaScript
How to run:
1. Copy the CJITS_Engineering_College_Website folder into XAMPP htdocs.
2. Start Apache in XAMPP.
3. Open http://localhost/CJITS_Engineering_College_Website/
4. Edit the contact details in index.php and page files as required.

Images supplied by the user:
- assets/images/logo.png
- assets/images/college.jpg
